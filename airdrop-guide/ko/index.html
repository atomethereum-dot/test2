Sectora 에어드랍 참여 방법, 단계별로.

이 가이드는 첫 클릭부터 Hash Node가 켜져서 카운트될 때까지 안내합니다. 각 단계에서 무엇을 누르는지, 무엇이 보여야 하는지, 무엇을 하면 안 되는지 스크린샷과 함께 정확히 알려 드립니다. 한 단계를 읽고, 해 보고, 다음으로 넘어가세요.

필요한 것은 딱 두 가지, 같은 지갑으로:

  • 1
    스테이킹 중인 #SECT이더리움 공식 스테이킹에 최소 100 #SECT. 파트 A.

두 가지가 모두 충족되면 에어드랍 카운트가 자동으로 시작됩니다. 가입도, 양식도 필요 없습니다.

이미 #SECT를 스테이킹 중이세요? 이미 참여 중입니다.

스테이킹은 더 이상 할 일이 없습니다. 아무것도 출금하지 마세요. 파트 A는 건너뛰고 바로 파트 B로 가세요. 스테이킹하는 것과 같은 지갑으로 Hash Node를 켜기만 하면 참여가 시작됩니다.

세 가지 보안 규칙. 절대 어기지 마세요.

1. 비밀 복구 구문(12개 또는 24개 단어)이나 개인 키를 절대 누구에게도 주지 마세요. Sectora는 절대 요청하지 않습니다. 2. sectoraorg.com만 사용하고, 매번 주소창을 확인하세요. 3. Sectora 직원이 “도와주겠다”며 먼저 연락하는 일은 없습니다. 그런 연락은 사기입니다.

컴퓨터 또는 휴대폰

컴퓨터든 휴대폰이든 둘 다 됩니다.

가지고 있는 것을 쓰세요. 단계는 같고, 지갑이 열리는 방식만 다릅니다.

컴퓨터에서

컴퓨터를 쓰시나요? 이렇게 하세요.

컴퓨터에서는 지갑이 브라우저 확장 프로그램(Chrome, Brave, Edge)입니다. 오른쪽 위에 작은 창으로 열립니다.

  1. Chrome, Brave, Edge에 지갑을 설치하세요(예: MetaMask, 공식 웹사이트에서만). 지갑을 열고 비밀번호로 잠금을 해제하세요.
  2. 스테이킹(파트 A): sectoraorg.com/staking을 열고 Connect wallet(지갑 연결)을 누르세요. 목록에서 지갑을 누르세요 (1). 오른쪽 위에 지갑 창이 열리면 연결을 누르세요 (2).
  3. 노드(파트 B): 같은 브라우저에서 sectoraorg.com/dashboard를 열고 지갑 연결을 누른 뒤 같은 지갑을 고르세요.

지갑 창이 안 보이나요? 브라우저 오른쪽 위의 퍼즐 아이콘을 누른 다음 지갑을 누르세요. 확장 프로그램이 없나요? 목록에서 Wallet on your phone(휴대폰의 지갑)을 고르고 휴대폰으로 QR 코드를 스캔하세요.

휴대폰에서

휴대폰을 쓰시나요? 먼저 이걸 읽으세요.

이 가이드의 모든 내용은 휴대폰에서도 됩니다. 지갑 앱(MetaMask, Trust Wallet, Coinbase Wallet 등)만 설치되어 있으면 됩니다.

  1. 스테이킹(파트 A): Chrome이나 Safari에서 sectoraorg.com/staking을 열고 Connect wallet(지갑 연결)을 누르세요. 목록에서 지갑 앱을 누르고, 앱에서 승인한 뒤 브라우저로 돌아오세요.
  2. 노드(파트 B): sectoraorg.com/dashboard를 열고 지갑 연결을 누르세요. 휴대폰에서는 MetaMask에서 열기(또는 사용하는 지갑)이 나타납니다. 누르면 대시보드가 지갑 앱 안에서 열립니다. 거기서 계속하세요.
  3. 지갑 앱 안에서는 모든 것이 바로 연결됩니다. 모든 단계를 같은 지갑 앱으로 하세요.

지갑 앱이 열리지 않으면 직접 앱을 열고, 내장 브라우저(보통 브라우저, 탐색, Discover)를 찾아 그곳에 주소를 입력하세요.

#SECT 스테이킹

#SECT를 공식 스테이킹에 넣습니다. 여전히 여러분의 것이며, 매초 보상이 쌓이고 에어드랍에도 반영됩니다. 이미 스테이킹 중이세요? 파트 B로 건너뛰기.

스테이킹 페이지는 영어로 열립니다. 오른쪽 위의 국기로 언어를 바꿀 수 있습니다. 여기서는 각 버튼을 영어 화면에 보이는 그대로 표시하고, 괄호 안에 번역을 넣었습니다.

B

파트 B · 단계 8–14

Hash Node 켜기

Hash Node는 Sectora 테스트넷(Sepolia)에서 작동합니다. 파트 B는 모두 무료: 가치가 없는 무료 테스트 코인을 사용합니다. 여기서는 절대 실제 돈을 쓰지 않습니다.

무료 · 테스트넷스테이킹과 같은 지갑자동으로 계속 켜짐
  1. 08파트 B

    대시보드

    대시보드를 열고 “지갑 연결” 누르기

    1. sectoraorg.com/dashboard를 여세요.
    2. 오른쪽 위의 지갑 연결을 누르세요.
    3. 휴대폰에서(Chrome 또는 Safari): 목록이 나타납니다. MetaMask에서 열기(또는 사용하는 지갑)을 누르면 대시보드가 지갑 앱 안에서 열립니다. 거기서 지갑 연결을 다시 누르세요.

    대시보드는 영어로 열립니다. 위쪽의 국기 메뉴에서 한국어로 바꾸면 이 스크린샷과 똑같이 보입니다.

    스테이킹한 것과 같은 지갑을 사용하세요. 다른 지갑의 노드는 에어드랍에 반영되지 않습니다.
  2. 09파트 B

    내 지갑

    지갑을 선택하고 테스트넷 승인하기

    1. “지갑 연결” 목록에서 사용하는 지갑을 누르세요(감지됨라고 표시됨).
    2. 지갑에서 연결을 누르세요.
    3. 대시보드가 지갑을 자동으로 Sepolia 테스트넷으로 바꿉니다. 지갑이 네트워크 변경이나 추가를 물으면 승인 또는 네트워크 전환을 누르세요.
    지갑에 Sepolia가 안 보이나요? 지갑 설정을 열고 “테스트 네트워크 표시”를 켠 뒤 다시 시도하세요.
  3. 10파트 B

    무료 가스

    가스용 무료 Sepolia ETH 받기

    1. 테스트넷의 모든 작업에는 약간의 Sepolia ETH가 필요합니다. 가치가 없는 무료 테스트 코인입니다.
    2. 대시보드에서 조금 내려 “이용 방법”로 가세요. 02 “무료 가스 받기” 상자에서 Sepolia ETH 받기를 누르세요.
    3. Google Cloud 페이지(영어)가 열립니다. 네트워크가 Ethereum Sepolia인지 확인하고, “Wallet address or ENS name”에 지갑 주소를 붙여 넣은 뒤 Get 0.05 Sepolia ETH를 누르세요. 요청하면 Google 계정으로 로그인하세요.
    4. 대시보드 탭으로 돌아오세요.
    주소는 어떻게 복사하나요? 지갑을 열고 위쪽의 계정 이름이나 주소를 누르면 자동으로 복사됩니다.
    Google이 이더리움 메인넷에 0.001 ETH가 필요하다고 하나요? Google 포싯은 이더리움에 실제 ETH를 0.001 이상 가진 지갑에만 Sepolia ETH를 줍니다. 지갑에 ETH를 조금 남겨 두고(파트 A에서도 필요합니다) 다시 시도하세요.
  4. 11파트 B

    무료 테스트 토큰

    무료 5,000 tSECT 받기

    1. 같은 상자에서 5,000 tSECT 받기를 누르세요.
    2. 지갑이 열리면 확인을 누르세요.
    3. 몇 초 기다리세요. “내 잔액”에 5,000 tSECT가 표시됩니다.
    tSECT는 금전적 가치가 없는 테스트 토큰입니다. 24시간마다 다시 받을 수 있습니다.
  5. 12파트 B

    해시 마켓

    Node Kit · 50 TH/s 구매하기

    1. “해시 마켓”까지 내리세요.
    2. 물리 노드 탭을 여세요 (1).
    3. 에어드롭 플랜 표시가 있는 50 TH/s · 4,300 tSECT 카드를 누르세요 (2). 이것이 에어드랍용 노드입니다.
    4. 50 TH/s 구매를 누르세요 (3).
    5. 지갑이 두 번 열립니다: 처음은 결제 허용, 두 번째는 구매 확정입니다. 두 번 모두 확인을 누르세요.
    4,300 tSECT는 단계 11에서 받은 무료 5,000 tSECT에서 나갑니다. 실제 돈은 쓰지 않습니다.
  6. 13파트 B

    내 노드

    노드 등록하기. 위치는 자동입니다.

    1. “내 노드”까지 내리세요.
    2. 노드 위치가 이미 감지되어 있고 (1) 이름도 이미 입력되어 있습니다. 아무것도 입력하지 않아도 됩니다.
    3. 노드 등록을 누르세요 (2).
    4. 지갑이 열리면 확인을 누르세요.
    위치에 대해. 당사 시스템이 연결 정보로 노드의 대략적인 위치를 감지해 자동으로 입력합니다. 네트워크에는 도시만 저장되며 주소는 절대 저장되지 않습니다. 위치가 틀렸나요(예: VPN 때문에)? “변경”을 눌러 고치세요.

    단계 13 · 플랜 B · “위치를 감지하지 못했습니다. 아래에 입력하세요.”가 보일 때만

    이유
    VPN, 광고 차단기 또는 매우 엄격한 브라우저 때문에 감지가 안 될 때가 있습니다. 그러면 위도와 경도 두 칸이 나타납니다.
    숫자 찾기
    Google 지도를 열고 내 도시를 검색하세요. 컴퓨터에서는 도시 중심을 마우스 오른쪽 버튼으로 클릭하고, 휴대폰에서는 길게 누르세요. 40.4168, -3.7038 같은 숫자 두 개가 보입니다.
    입력하기
    첫 번째 숫자는 위도 (1)에, 두 번째 숫자는 경도 (2)에 넣으세요. 마이너스 기호가 있으면 그대로 두세요.
    그다음
    노드 등록을 누르고 지갑에서 확인하세요. 집이 아니라 도시를 사용하세요.
  7. 14파트 B

    완료

    완료: 노드가 켜졌습니다

    1. 버튼이 등록됨으로 바뀝니다.
    2. 노드가 네트워크 지도에 나타납니다. 지금부터 카운트됩니다.
    가능탭을 닫아도 됩니다노드는 네트워크에서 스스로 켜진 상태를 유지합니다.
    가능컴퓨터를 꺼도 됩니다노드는 컴퓨터나 휴대폰에 의존하지 않습니다.
    금지노드를 절대 비활성화하지 마세요노드를 비활성화하거나 끄는 버튼을 누르거나 그런 트랜잭션에 서명하지 마세요. 꺼져 있는 동안에는 다시 켤 때까지 카운트되지 않습니다.
    파트 B 완료. 에어드랍에 참여 중입니다.

    스테이킹 + 노드 켜짐, 같은 지갑으로. 카운트가 진행 중입니다.

문제 해결 · 빠른 답변

뭔가 안 되나요? 먼저 여기를 보세요.

스테이킹 페이지에서 “Not enough ETH”

파트 A는 실제 이더리움을 사용합니다. 같은 지갑에 ETH(이더리움)를 조금 추가하고 다시 시도하세요.

대시보드에서 가스 부족

파트 B는 무료 Sepolia ETH를 사용합니다. 단계 10을 다시 하세요.

Google 포싯이 이더리움에 0.001 ETH를 요구함

Google 포싯을 쓰려면 지갑에 이더리움 실제 ETH가 0.001 이상 있어야 합니다. 조금 남겨 두고 다시 시도하거나 고객지원에 문의하세요.

지갑에 Sepolia가 안 보임

지갑 설정에서 “테스트 네트워크 표시”를 켜고 대시보드를 새로고침하세요.

“Switch your wallet to the Ethereum network”

스테이킹 페이지에서 네트워크가 잘못되어 있습니다. 지갑에서 Ethereum(이더리움 메인넷)을 선택하고 새로고침하세요.

“You do not have that many #SECT in your wallet”

#SECT가 부족하다는 뜻입니다. 더 적은 수량을 입력하거나 구매 가이드로 더 구매하세요.

Node Kit를 살 tSECT가 부족함

단계 11에서 5,000 tSECT를 받으세요. 오늘 이미 받았나요? 24시간 후에 다시 받으세요.

노드에 다른 지갑을 사용했음

반영되지 않습니다. 대시보드에서 스테이킹 지갑을 연결하고 파트 B를 다시 하세요.

위치가 감지되지 않거나 틀림

“변경”을 누르거나 단계 13의 플랜 B를 따르세요. 집이 아니라 도시를 쓰세요.

지갑 창이 열리지 않음

지갑 앱이나 확장 프로그램을 직접 여세요. 요청이 거기서 기다리고 있습니다. 휴대폰에서는 승인 후 브라우저 탭으로 돌아오세요.

컴퓨터를 계속 켜 둬야 하나요?

아니요. 등록하면 노드는 스스로 켜진 상태를 유지합니다. 비활성화만 하지 마세요.

참여하려면 스테이킹을 출금해야 하나요?

아니요. 절대 아닙니다. 스테이킹 중인 #SECT는 그대로 반영되고, 스테이킹 보상도 계속 받습니다.

파트 B는 돈이 드나요?

아니요. tSECT와 Sepolia ETH는 가치가 없는 무료 테스트 코인입니다.
