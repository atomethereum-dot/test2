Post-quantum · threat model

Stolen today. Unreadable tomorrow.

Harvest now, decrypt later: encrypted traffic, custody records and public keys are intercepted today and stored for years, waiting for a quantum computer to break RSA and elliptic-curve keys. Shield wraps the same data in NIST's post-quantum standards, so what is stolen stays unreadable.

What Shield protects

One engine, applied at every layer of the network

Built on standardized post-quantum cryptography

NIST finalized these algorithm families in 2024 (FIPS 203/204/205) — Shield is built on that same foundation
FIPS 203 · ML-KEM

Key encapsulation

Lattice-based key exchange (CRYSTALS-Kyber family) secures every session and message between validators, custody records and the network's live data feeds.

FIPS 204 · ML-DSA

Digital signatures

Lattice-based signatures (CRYSTALS-Dilithium family) authenticate custody transfers and validator actions — built to remain unforgeable even against quantum attacks.

FIPS 205 · SLH-DSA

Hash-based signatures

A stateless hash-based signature scheme (SPHINCS+ family) backs long-horizon custody records — the class of asset that has to stay verifiable for decades.

Why this matters for tokenized assets

Custody records for real-world assets have to stay valid for as long as the property does — often decades
